# Contributing

Start with `AGENTS.md`, `docs/STATUS.md`, and `docs/RESUME.md`.

Changes should be small enough that their behavioral claim can be tested independently. Prefer one causal correction plus its evidence over a large speculative port. Source-derived constants should cite the source function/resource in the accompanying report.

Do not commit proprietary game data. A patch that requires an original asset should include a reproducibility note identifying archive/resource IDs and the expected converted-package contract, not the asset bytes.

Commit messages should state what was closed and what remains open. For major gameplay milestones, add a report under `docs/reports/` and update the status/resume documents in the same commit.
