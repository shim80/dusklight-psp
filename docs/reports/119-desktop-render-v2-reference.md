# Rapport 119 — Référence rendu v2

L’oracle produit des flux séparés pour environnement, matériaux et ombres,
ainsi que 78 soumissions de rendu. Ils couvrent les scènes réellement
traversées F_SP102 et F_SP108.

La caméra est `MATCH_WITH_TOLERANCE`. Les équivalents GE fixed-function pour
environnement, matériaux et ombres sont `EXPECTED_PLATFORM_DIFFERENCE`.
Le rapport ne prétend ni égalité pixel ni performance de PSP physique.
